# House Seats Presents — Proposal

Interactive proposal & strategic execution deck for the **House Seats Presents** January 1, 2027 launch.

- Single self-contained `index.html` (all CSS/JS inline, Chart.js from CDN).
- Slide-based presentation deck — arrow keys / space to navigate, `F` for fullscreen.
- Access is gated by a client-side code (soft gate for casual privacy, not real security).
- Built from the same brand + interaction system as the Elfve × LFV proposal.

## Run
Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
# then open http://localhost:8000
```

Add `?print` to the URL to bypass the access gate for PDF export.

Access code: `houseseats2027`
